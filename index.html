System notes & service limits

  • All editing, validation, audio extraction, rendering and workbook generation run on this device using WebAssembly/JavaScript. No server-side retention applies.
  • FFmpeg WebAssembly and Whisper model files are fetched from public CDNs when first needed. Those downloads use bandwidth and may be cached by your browser. CDN operators may receive normal request metadata, but not your draft media.
  • Whisper Tiny English is an optional model download (typically tens to roughly 100 MB, depending on model files). First-run time and RAM use vary. CPU fallback is slower; WebGPU support varies by browser/device.
  • FFmpeg.wasm has much lower throughput and practical memory limits than desktop FFmpeg. Large/long/high-resolution videos may fail or exhaust browser memory. There is no fixed universal max file size; this app warns at 500 MB.
  • Browser storage and memory quotas vary by device and browser. This app does not persist your media in IndexedDB or remote storage. Downloads are controlled by the browser.
  • GitHub Pages, if later used for static hosting, currently documents a 1 GB published-site limit, 100 GB/month soft bandwidth limit, and 10-minute deployment timeout. Static hosting retains only application files, not user-selected video.
